# 🥖 Breadly Bakery — Artisanal Boulangerie & Patisserie

A production-grade, 6-page handcrafted artisanal bakery website built with modern HTML5, CSS3, and vanilla JavaScript. Features warm editorial typography, responsive layouts, smooth scroll reveals, and interactive reservations.

---

## 🌟 Pages Overview

1. **Home (`index.html`)**: Cinematic hero viewport, live oven status ticker, craft story pillars, signature product showcase with interactive reserve toasts, customer testimonials, and visit bookend.
2. **Daily Menu (`menu.html`)**: Category filter tabs (Wild Sourdough, Laminated Pastries, Patisserie & Cakes) with pricing and daily specials.
3. **Our Craft (`about.html`)**: Founding narrative of wild culture starter 'Bob', milestone timeline, 3 craft values, and head baker profiles.
4. **Bakehouse Gallery (`gallery.html`)**: Responsive masonry visual journal, documentary video preview, and Instagram highlights.
5. **Custom Bakes (`order.html`)**: Bespoke celebration cake inquiry form with dietary preferences (Eggless, Nut-Free) and FAQ accordion.
6. **Visit & Contact (`contact.html`)**: Store hours, weekly oven schedule, direct inquiry form, and interactive map embed.

---

## 🛠️ Tech Stack & Architecture

- **Markup**: Semantic HTML5 with complete WCAG AA accessibility standards
- **Styling**: Pure modern CSS custom properties (Ember Kitchen warm palette), CSS Grid & Flexbox, fluid clamp typography
- **Typography**: Cormorant Garamond (Display Serif) + Plus Jakarta Sans (Clean Body) via Google Fonts
- **Interactivity**: Lightweight Vanilla JavaScript (`main.js`), GSAP ScrollTrigger reveals, SplitType word animations, native IntersectionObserver
- **Media**: 100% Free & Royalty-Free Unsplash photography under the Unsplash license

## 🚀 Quick Start

1. Clone or download the repository:
   ```bash
   git clone https://github.com/ManishRoySkyDigi/Bakery.git
   ```
2. Open `index.html` directly in any modern web browser or serve with your favorite local server:
   ```bash
   # Using VS Code Live Server or Python
   python -m http.server 3000
   ```
